# 코드 컨벤션

이 문서는 기존 Java 코드의 구조와 서식을 정리하고, 새로 작성하거나 기능상 수정하는 코드에 적용할 중괄호와 괄호 표기를 정의한다.

## 디렉터리와 이름

```text
src/
├── main/java/com/holub/
│   ├── life/       게임 창, 게임판, 셀, 시계
│   ├── ui/         공용 Swing 메뉴와 색상
│   ├── io/         파일 선택
│   ├── tools/      이벤트 발행과 로깅
│   └── asynch/     스레드 동기화
└── test/java/com/holub/life/  게임 코드 테스트 경로
```

- 디렉터리는 `package` 선언과 일치시키고, 최상위 타입은 타입 이름과 같은 `.java` 파일에 둔다.
- 패키지는 소문자, 클래스와 인터페이스는 `UpperCamelCase`, 메서드/필드/지역변수는 `lowerCamelCase`, 상수는 `UPPER_SNAKE_CASE`를 사용한다.
- 파일은 `package`, `import`, 타입 설명, 타입 선언 순서로 구성한다.

## 중괄호와 괄호

- **클래스와 인터페이스**의 여는 `{`는 선언 바로 다음 줄에 단독으로 쓰고, 멤버는 그다음 줄부터 한 탭 들여쓴다.
- **메서드**의 여는 `{`는 선언 바로 다음 줄에 쓴다. `{` 뒤에 탭 하나를 넣고 같은 줄에 본문의 첫 문장을 쓴다. 이후 문장은 다음 줄부터 같은 깊이로 들여쓰고, 닫는 `}`는 선언과 같은 깊이의 별도 줄에 둔다.
- **괄호**는 `if( condition )` 형태로 통일한다. 키워드나 이름과 여는 `(` 사이를 붙이고, 조건/인자/매개변수가 있으면 괄호 안쪽 양끝에 공백을 한 칸씩 둔다. 내용이 없으면 `clear()`처럼 붙여 쓴다.

```java
final class PatternSelection
{
	private LifePattern pendingPattern;

	void select( LifePattern pattern )
	{	if( pattern == null )
			return;

		pendingPattern = pattern.copy();
	}
}
```

## 나머지 서식

- **들여쓰기와 정렬**은 Java 코드의 기존 탭 들여쓰기를 따른다. 선언, 인자, 주석을 열에 맞춘 코드도 있으므로 같은 블록에서는 주변 정렬에 맞춘다.
- **긴 줄과 빈 줄**은 기존 코드처럼 인자나 조건을 읽기 좋은 위치에서 나누고, 이어지는 줄은 주변의 들여쓰기 방식에 맞춘다. 메서드 사이와 역할이 다른 문장 묶음 사이는 빈 줄로 구분한다.
- **주석**은 기존 소스에 맞춰 영어로 작성한다. 타입과 메서드의 동작 설명에는 Javadoc을, 구현 내부 설명에는 `//`를 사용한다.
